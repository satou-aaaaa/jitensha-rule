# 自転車ルールみきわめ

その乗り方、してよい？だめ？ 自転車に乗る場面が、交通の決まりで「してよい」か「だめ」かを当てながら、自転車のルールが身につくゲームです。

- 遊ぶ: <https://satou-aaaaa.github.io/jitensha-rule/>
- 1問ずつ、場面が「○ してよい」か「✕ だめ」かを選ぶか、3つの場面から「だめなのはどれ？」「してよいのはどれ？」を選びます。答えると、なぜそうなのかと、反則金（青切符）がある場合はその金額・出典が出ます。
- 今日の5問（○✕・○✕・どれ・○✕・どれ）と上級（「どれ？」×3・ヒントなし）はだれでも同じで1日1回。とことん（何問続けて当てられる？）と練習（なかまを選ぶ）は何度でも。
- 出会った場面は「ルール帳」に集まり、いつでも答え・なぜ・反則金を読めます。実績・カレンダー（7日前まであとから遊べる）もあります。時間制限はありません。
- 場面は46。なかまは「通る場所」「交差点・踏切」「乗り方」「夜・お酒・そなえ」の4つ。
- 記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：文字（Google Fonts）を読み込むとき、Google に IP アドレスが届きます。「Xで投稿」「LINEで送る」「結果をシェア」を押したときだけ、結果の文が選んだ先に渡ります（場面や答えは入りません）。

## 決まりの出どころ

- 決まりと反則金は、警察庁の [自転車ルールブック](https://www.npa.go.jp/bureau/traffic/bicycle/pdf/rulebook.pdf)（「自転車を安全・安心に利用するために ー自転車への交通反則通告制度（青切符）の導入ー」令和7年9月）と、[自転車ポータル「自転車の交通ルール」](https://www.npa.go.jp/bureau/traffic/bicycle/portal/rule.html) から書き写しました（2026-11-07 に確かめた）。
- 反則金（青切符）は 2026年4月1日から、16歳以上が対象です。お酒を飲んでの運転など重い違反は赤切符（刑事手続）になります。金額はルールブック本文に書かれているものだけを出し、書かれていないものは出していません。
- 傘差し・イヤホンなどは各都道府県の公安委員会の規則で決まっています（ルールブックでは全部の都道府県で禁止）。
- このゲームは決まりを覚えるためのもので、法律の相談の代わりにはなりません。まちがいを見つけたら、[感想のフォーム](https://github.com/satou-aaaaa/jitensha-rule/issues/new?template=feedback.yml)で教えてください。
